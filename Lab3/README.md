# Lab 3

## Мета роботи
Ознайомитися з роботою зі сховищами даних в Android та навчитися зберігати і відображати інформацію.

## Завдання
Модифікувати програму з лабораторної роботи №2, додавши:
- збереження результатів у сховище (файл або база даних)
- повідомлення користувача про успішний запис
- кнопку "Відкрити" для перегляду збережених даних

## Опис роботи
На основі попередньої лабораторної роботи було розширено функціональність додатку.

### Реалізовано:
- при натисканні кнопки "OK":
    - виконується обчислення
    - результат зберігається у файл (внутрішнє сховище)
    - користувач отримує повідомлення про успішний запис

- додано кнопку "Відкрити":
    - відкриває нову Activity
    - у новій Activity відображаються збережені результати

- якщо дані відсутні:
    - виводиться повідомлення про порожнє сховище

### Додатково:
(якщо не робила — можеш залишити або видалити)
- можливість очищення даних

## Висновок
У результаті виконання лабораторної роботи було:
- вивчено роботу зі сховищами даних в Android
- реалізовано запис і читання даних
- освоєно перехід між Activity
