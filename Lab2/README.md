# Lab 2

## Мета роботи
Дослідити створення та взаємодію з компонентом Fragment та навчитися використовувати кілька фрагментів в одному Activity.

## Завдання
Розробити Android-додаток, який:
- складається з двох фрагментів
- перший фрагмент — введення даних
- другий фрагмент — відображення результату
- забезпечує взаємодію між фрагментами

## Опис роботи
Було реалізовано додаток з одним Activity та двома фрагментами:

### InputFragment:
- введення двох чисел
- вибір операції (додавання, віднімання, множення, ділення)
- кнопка "OK" для обчислення

### ResultFragment:
- відображення результату
- кнопка "Cancel" для повернення назад

Реалізовано:
- передачу даних між фрагментами через інтерфейси
- перевірку введених даних
- обробку помилок (наприклад, ділення на нуль)

## Висновок
У процесі виконання роботи було вивчено:
- створення Fragment
- взаємодію між Activity та Fragment
- передачу даних між компонентами
- управління фрагментами через FragmentManager
