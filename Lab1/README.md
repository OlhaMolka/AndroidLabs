# Lab 1

## Мета роботи
Ознайомитися з основами розробки Android-додатків та створенням простого користувацького інтерфейсу.

## Завдання
Розробити Android-додаток, який:
- дозволяє вводити два числа
- обирати арифметичну операцію
- відображає результат обчислення

## Опис роботи
У ході роботи було створено додаток з одним Activity, який містить:
- два поля введення чисел (EditText)
- групу перемикачів (RadioGroup) для вибору операції:
    - додавання
    - віднімання
    - множення
    - ділення
- кнопку "OK" для виконання обчислення
- текстове поле для відображення результату

Реалізовано перевірку:
- на заповненість полів
- на ділення на нуль

## Висновок
У результаті виконання лабораторної роботи було освоєно:
- створення простого UI в Android
- роботу з Activity
- обробку подій (натискання кнопки)
- базову логіку обчислень
