# Лабораторна робота № 4. Дослідження способів роботи з метаданими

## Мета роботи

Ознайомитися з можливостями роботи з мультимедійними файлами в Android та навчитися відтворювати аудіо і відео.

## Завдання

Розробити Android-додаток, який дозволяє обирати медіафайли з пам’яті пристрою та відтворювати їх, реалізувавши базові елементи керування відтворенням (Play, Pause, Stop).

## Опис роботи

У ході виконання лабораторної роботи було створено Android-додаток для роботи з мультимедійними файлами. Реалізовано можливість вибору файлу з пам’яті пристрою за допомогою системного інтенту. Додаток визначає тип обраного файлу (аудіо або відео) та відповідно використовує MediaPlayer для відтворення аудіо або VideoView для відтворення відео. Для керування відтворенням реалізовано кнопки «Відтворити», «Пауза» та «Зупинити». Також забезпечено коректну обробку ресурсів, зокрема звільнення MediaPlayer після завершення відтворення.

## Висновок

У результаті виконання лабораторної роботи було освоєно роботу з мультимедійними компонентами Android, зокрема MediaPlayer та VideoView, реалізовано відтворення аудіо і відео, а також базове керування відтворенням у мобільному додатку.
