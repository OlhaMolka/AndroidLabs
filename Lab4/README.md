# 📱 Лабораторна робота №4

## Робота з аудіо та відео файлами в Android

### 🎯 Мета роботи

Ознайомитися з можливостями Android щодо відтворення мультимедійних файлів (аудіо та відео), а також реалізувати базові елементи керування відтворенням.

---

### 📌 Умови завдання

Розробити Android-додаток, який:

* дозволяє обрати файл із пам’яті пристрою;
* визначає тип файлу (аудіо або відео);
* відтворює вибраний файл;
* підтримує керування:

  * ▶️ відтворення
  * ⏸ пауза
  * ⏹ зупинка

---

### 🛠 Використані технології

* Kotlin
* Android SDK
* VideoView — для відтворення відео
* MediaPlayer — для відтворення аудіо
* Intent (ACTION_GET_CONTENT) — для вибору файлу

---

### 📱 Опис роботи програми

Після запуску додатку користувач може:

1. Натиснути кнопку **«Обрати файл»** та вибрати медіафайл.
2. Натиснути **«Відтворити»** для запуску.
3. Використовувати:

   * **«Пауза»** — для тимчасової зупинки;
   * **«Зупинити»** — для повного завершення відтворення.

Програма автоматично визначає тип файлу:

* якщо це відео — використовується VideoView;
* якщо аудіо — використовується MediaPlayer.

---

### ⚙️ Основні компоненти

* `MainActivity.kt` — логіка роботи програми
* `activity_main.xml` — інтерфейс користувача
* `AndroidManifest.xml` — дозволи та конфігурація

---

### 📷 Результат роботи

Додаток успішно:

* відкриває медіафайли
* відтворює аудіо та відео
* підтримує керування відтворенням

---

У ході виконання лабораторної роботи було створено Android-додаток для роботи з мультимедійними файлами. Отримано практичні навички роботи з MediaPlayer, VideoView та системними інтентами для вибору файлів.
