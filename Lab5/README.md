## ЛАБОРАТОРНА РОБОТА №5
# Робота з датчиками Android
# Тема роботи:

# Розробка Android-додатку для зчитування та відображення даних з датчика акселерометра

# Мета роботи:

Ознайомитися з роботою вбудованих датчиків Android-пристрою, навчитися отримувати та обробляти дані з датчика акселерометра, а також відображати їх у користувацькому інтерфейсі.

# Постановка завдання:

Розробити Android-додаток, який:

отримує дані з акселерометра;
відображає значення по осях X, Y, Z;
реагує на зміну положення пристрою;
реалізує обробку отриманих даних.

# Опис реалізації:

У ході виконання лабораторної роботи було створено додаток, який використовує датчик акселерометра для визначення положення пристрою у просторі.

# Інтерфейс користувача:

Інтерфейс реалізовано за допомогою LinearLayout і містить:

три TextView для відображення значень X, Y, Z.

# Робота з датчиком:
Використано SensorManager для доступу до датчиків.
Отримано акселерометр через:
Sensor.TYPE_ACCELEROMETER
Реалізовано інтерфейс SensorEventListener.

# Обробка даних:
У методі onSensorChanged() отримуються значення:
X
Y
Z
Дані відображаються у відповідних TextView.
Додано просту логіку обробки:
при різких змінах значень виводиться повідомлення (наприклад, "РУХ!").

# Тестування:

Для тестування використовувався емулятор Android Studio з можливістю зміни значень сенсорів через Extended Controls → Virtual Sensors → Device Pose.

Використані компоненти:
SensorManager
Sensor
SensorEventListener
TextView
LinearLayout
Результати роботи:

Було створено Android-додаток, який у реальному часі відображає дані з акселерометра та реагує на зміну положення пристрою.

# Висновок:

У процесі виконання лабораторної роботи було отримано практичні навички роботи з датчиками Android, зокрема акселерометром. Було реалізовано зчитування, обробку та відображення даних у реальному часі, що є важливим для створення інтерактивних мобільних додатків.
