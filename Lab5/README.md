# Лабораторна робота №5. Робота з датчиками Android

## Мета роботи

Ознайомитися з роботою вбудованих датчиків Android-пристрою, навчитися отримувати та обробляти дані з датчика акселерометра, а також відображати їх у користувацькому інтерфейсі.

## Завдання

Розробити Android-додаток, який отримує дані з акселерометра, відображає значення по осях X, Y, Z, реагує на зміну положення пристрою та реалізує обробку отриманих даних.

## Опис роботи

У ході виконання лабораторної роботи було створено Android-додаток, який використовує датчик акселерометра для визначення положення пристрою у просторі. Інтерфейс користувача реалізовано за допомогою LinearLayout і містить три текстові поля (TextView) для відображення значень по осях X, Y та Z. Для роботи з датчиком використано SensorManager, за допомогою якого отримано доступ до акселерометра через Sensor.TYPE_ACCELEROMETER, а також реалізовано інтерфейс SensorEventListener для обробки змін значень сенсора. У методі onSensorChanged() зчитуються значення по осях X, Y та Z, які відображаються у відповідних елементах інтерфейсу. Додатково реалізовано обробку даних, зокрема визначення руху пристрою при різких змінах значень. Для тестування додатку використовувався емулятор Android Studio з можливістю зміни параметрів сенсорів через меню Extended Controls → Virtual Sensors → Device Pose.

## Висновок

У процесі виконання лабораторної роботи було отримано практичні навички роботи з датчиками Android, зокрема акселерометром, реалізовано зчитування, обробку та відображення даних у реальному часі, що є важливим для створення інтерактивних мобільних додатків.
