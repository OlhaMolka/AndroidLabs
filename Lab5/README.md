# Lab5 — Робота з датчиками (Android)

# Опис

Додаток для зчитування та обробки даних з акселерометра.

Програма відображає значення по осях:

* X
* Y
* Z

Також реалізовано обробку даних для визначення стану пристрою.

---

Функціонал

* Виведення значень акселерометра (X, Y, Z)
* Визначення стану пристрою:

  * **РУХ!** — якщо значення великі
  * **РІВНО** — якщо пристрій лежить горизонтально
  * **НАХИЛ** — якщо пристрій нахилений

---

# Використані технології

* Kotlin
* Android SDK
* SensorManager
* Accelerometer (TYPE_ACCELEROMETER)

---

# Як запустити

1. Відкрити проект в Android Studio
2. Запустити емулятор або підключити телефон
3. Для емулятора:

   * Extended Controls → Virtual Sensors → Device Pose
   * змінювати X/Y
