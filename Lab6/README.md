Вільна тема
Тема роботи:

Розробка Android-додатку “Список задач (To-Do List)”

Мета роботи:

Ознайомитися з процесом створення Android-додатку з використанням інтерфейсу користувача, обробки подій та роботи зі списками даних. Закріпити навички створення власного проєкту на довільну тему.

Постановка завдання:

Розробити Android-додаток, який дозволяє користувачу:

вводити текст задачі;
додавати задачу до списку;
відображати список задач;
видаляти задачу натисканням;
забезпечити зручний та сучасний інтерфейс.
Опис реалізації:

У ході виконання роботи було створено Android-додаток з наступною функціональністю:

🔹 Інтерфейс користувача:

Інтерфейс реалізовано за допомогою LinearLayout.
Він містить:

заголовок додатку;
поле введення (EditText);
кнопку додавання (Button);
список задач (ListView).

Для покращення вигляду було створено окремий layout для елементів списку (item_task.xml), що дозволило відображати задачі у вигляді карток.

🔹 Логіка роботи:
Для збереження задач використовується список (ArrayList<String>).
Відображення здійснюється через ArrayAdapter.
При натисканні кнопки:
текст з поля вводиться у список;
список оновлюється;
поле очищується.
При натисканні на елемент списку:
задача видаляється.
🔹 Дизайн:

Було використано:

власні кольори (colors.xml);
відступи та стилізацію;
сучасний вигляд кнопок;
картковий стиль елементів списку.
Використані компоненти:
EditText
Button
ListView
TextView
ArrayAdapter
LinearLayout
Результати роботи:

Було створено повноцінний Android-додаток для роботи зі списком задач, який має зручний інтерфейс та базову функціональність керування задачами.

Висновок:

У ході виконання лабораторної роботи було отримано практичні навички створення Android-додатків, роботи з інтерфейсом користувача та обробки подій. Розроблений додаток демонструє базові можливості створення інтерактивних програм на платформі Android.
